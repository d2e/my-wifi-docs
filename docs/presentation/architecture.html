Step 1 — System Architecture (draw.io)

Whole-home system blueprint

① Flat L3 Subnet

Nokia ONT (.1) is master DHCP. All APs run L2 bridging. Zero double-NAT; latency differences are switch hops.

② Jio AX6000 (.50) Automation Hub

Primary Wi-Fi 6 AP, mesh.html host, ucode pollers, and local USB 2.0 media storage direct to Nokia.

③ Chained SPOF Risk

AP #2 (.98) carries TP-Link (.12) uplink. Chained outage risk is isolated from the Jio hub.

Single-Session Telnet Budgeting

Huawei APs allow exactly one telnet session. The poller batches commands into a single budgeted visit and closes cleanly, avoiding locks.

Zero User-Facing Latency

Web requests never wait on telnet or CLI parsing. The UI reads memory JSON instantly, completely decoupled from hardware I/O.

Operational Principles

Four rules, each bought with a real outage

  • A write that reports success is not evidence it took effect Settings reading back correctly, APIs returning rc=0, commands exiting 0 — all three have lied on this hardware. Verify against subsystem state (dumpsys, CEC bus, display wifi radio).
  • The end state looking right doesn’t mean the mechanism ran A keep-alive sat broken for weeks while its monitor stayed green, because the processes it was supposed to revive happened to already be running.
  • Deploy first, then test Running the test suite locally tests the stale copy and passes for the wrong reason. Always copy to the target router before running regression tests.
  • A confident explanation that contradicts the timeline is still wrong An exhaustively argued “soundbar firmware defect” was disproved by a reboot — the user said it worked yesterday, which no permanent defect explains.
